## Sobre mim

Sou estudante de **Sistemas de Informação na PUC-Campinas** e desenvolvedor em formação, com interesse especial em desenvolvimento **back-end e full stack**.

Gosto de transformar ideias em aplicações funcionais, organizando desde as regras de negócio e o banco de dados até a interface e os testes. Atualmente, meu principal projeto é o **Royale Hub**, uma plataforma web de estatísticas e comunidade para Clash Royale.

- Criando interfaces responsivas com **HTML, CSS e JavaScript**
- Trabalhando com **APIs, bancos relacionais, autenticação e automações**

## Projeto em destaque

### ⚔️ Royale Hub

Plataforma full stack para jogadores de Clash Royale acompanharem perfis, rankings, cartas, decks e estatísticas do meta.

**Principais pontos do projeto:**

- Integração preparada para a API oficial do Clash Royale
- Perfis de jogadores, rankings e histórico de partidas
- Analisador de decks e estatísticas por carta
- Login social e personalização de perfil
- Sistema Premium, Hub Coins e loja de itens digitais
- Cache, coleta de dados e prevenção de partidas duplicadas
- Testes automatizados de backend, segurança e concorrência
- Testes de interface em desktop e celular com Playwright
- Pipeline de CI com auditoria de dependências
